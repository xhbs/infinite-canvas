# 相机四维编码：镜头设计与检查

改编自 [seedance2.5-prompt-skill / camera-codec.md](https://github.com/ye4wzp/seedance2.5-prompt-skill/blob/b093438a133ebc3fe81cd1be214271a222516919/references/camera-codec.md)，保留 Z/Y/X/F 分类，结合萌宠叙事调整。原作版权与 MIT 许可见 [许可文件](../licenses/seedance2.5-prompt-skill-MIT.txt)。

Z/Y/X/F 是设计镜头的分类工具，不是 Seedance 官方参数或需要模型解析的代码。先从剧情确定观众要看见的信息，再选景别、机位、光学与构图；最终提示词写成自然语言。基础规则见 [storyboard-rules.md](storyboard-rules.md)。

## 镜头描述公式

`观看目的 + Z 景别 + Y 高度与俯仰 + X 方位 + F 光学/视角/构图 + 固定或运动路径 + 速度节奏 + 必要连续性约束`

- Z/Y/X 用来检查每镜的取景和机位，F 按表达需要选用；不要求每镜填满所有光学属性或写焦段数值。
- 机位高度与镜头俯仰分别描述；方位指摄影机相对主体的位置，横移、绕行与原地摇镜分别描述。
- 编码可在审核表中辅助标注，但必须同时写中文含义；最终正文不靠 `Z5+Y4+X2` 代替画面描述。

## Z：景别、距离与信息量

景别按实际取景范围判断，不用固定摄影距离推算。同一景别可由不同距离和焦段获得。动物的取景按其姿态与身体结构判断，不机械套用人的胸口、腰和膝盖。

| 编码 | 景别 | 萌宠取景参照 | 用途 |
| --- | --- | --- | --- |
| Z1 | 大特写 | 瞳孔、鼻尖、爪尖等极小局部 | 关键线索或强烈感官细节 |
| Z2 | 特写 | 眼部、口鼻、爪子与所持道具的局部 | 展示动作细节和结果 |
| Z3 | 近景 | 完整脸部及少量肩颈 | 可读表情与视线变化 |
| Z4 | 中近景 | 头、肩及前爪活动区域 | 表情和局部操作同框 |
| Z5 | 中景 | 足以看清主要肢体交互的身体范围 | 递物、烹饪、两角色互动 |
| Z6 | 四分之三身 | 多数身体，必要时保留后肢或支撑部位 | 重心和姿态；按动物体态调整 |
| Z7 | 全景 | 完整身体及动作所需空间 | 起跳、落地、奔跑路线 |
| Z8 | 远景 | 主体较小，环境关系清楚 | 交代路线、距离与角色关系 |
| Z9 | 大远景 | 大范围环境，主体很小 | 必要的空间建立或尺度表达 |

关键爪部操作不能藏在只看脸的构图中；全身动作不能因追求表情近景而被裁掉。景别变化必须带来新信息，不强制按远到近排列。

## Y：机位高度与俯仰角

Y 编号表示观看角度的速记。实际镜头仍须交代摄影机相对动物眼睛、台面或地面的高度，以及镜头向上、水平或向下看。

| 编码 | 角度类别 | 写法参照 | 可能的表达作用 |
| --- | --- | --- | --- |
| Y7 | 垂直顶视 | 摄影机位于操作面正上方，镜头垂直向下 | 桌面布局、食材排列、路线 |
| Y6 | 明显俯视 | 高于主体眼睛，明显向下俯拍 | 空间关系、局促或渺小 |
| Y5 | 轻微俯视 | 略高于眼睛，轻微向下 | 观察动作和台面 |
| Y4 | 平视 | 与主体眼睛近乎等高，水平拍摄 | 日常互动、平等观看 |
| Y3 | 轻微仰视 | 略低于眼睛，轻微向上 | 出场、姿态强调 |
| Y2 | 明显仰视 | 低于主体，明显向上仰拍 | 体量、力量或喜剧夸张 |
| Y1 | 贴地虫视 | 摄影机贴地并大幅向上 | 极低视角下的尺度变化 |

“低机位”不等于仰拍：贴地摄影机可以水平看猫，也可以向上看桌边。角度的情绪含义取决于剧情，不把俯视固定等同弱小、仰视固定等同强大。

## X：相对主体的方位

| 编码 | 方位 | 取景特点 |
| --- | --- | --- |
| X1 | 正面，约 0° | 脸部和正面操作；角色是否看镜头另定 |
| X2 | 四分之三侧，约 45° | 同时看到脸部与身体纵深，适合互动和操作 |
| X3 | 正侧面，约 90° | 轮廓、运动方向、角色间距离 |
| X4 | 背面，约 180° | 展示面向的目标、遮蔽面部信息 |

按需要补“主体左前方/右前方”“路线外侧”“台面另一侧”等实际位置。方位不能替代画面左右、视线方向和行动轴线；同镜多人要说明以谁为参照。侧面固定镜头不意味着横移或环绕。

## F：光学、观看身份与构图

### 光学选择

焦段仅为全画幅等效的视觉参照，不是生成接口参数。透视还取决于摄影距离，景深还受光圈、对焦距离等影响；不把某个焦段写成固定虚化程度。

| 参考焦段 | 可选视觉效果 | 注意事项 |
| --- | --- | --- |
| 18–24mm，超广角至广角 | 宽空间、近大远小、贴近动作 | 近距离容易夸大猫鼻和爪部，边缘可能拉伸 |
| 35mm，偏广的常用焦段 | 主体与环境同时可读 | 适合操作关系与日常空间，不自动绑定深景深 |
| 50mm，标准焦段 | 较自然的局部叙事取景 | 依据距离和取景选择，不设为所有镜头默认值 |
| 85mm，中长焦 | 从较远位置取表情或细节、压缩背景关系 | 需保留动作范围，避免过浅景深遮掉关键道具 |
| 135mm 及以上，长焦 | 远处观察、背景压缩 | 只在这种观看距离确有必要时选用 |

- **浅景深**：明确什么清晰、什么虚化；猫眼和关键操作若都要看清，不能只让鼻尖或单眼合焦。
- **深景深**：需要同时交代前后角色、台面操作和空间关系时采用。
- **拉焦**：写清焦点起点、终点和触发节点，例如“爪子停住时，焦点由锅中食物转到猫眼”。拉焦不等于推镜或切镜。
- **散景**：仅在背景光源和叙事需要支持时描述，不为散景额外添加灯串。
- **微距、鱼眼、变形宽银幕等**：作为明确的风格选择，不自动叠加；需要时说清微小细节、畸变或光晕的实际效果。

### 观看身份

| 类型 | 必须交代的信息 |
| --- | --- |
| 主观 POV | 属于谁的视线，看向什么；不得同时无说明地展示该角色全身 |
| 过肩 OTS | 谁的肩背在前景，谁是清晰主体，两者视线关系 |
| 遮挡观看 | 透过门缝、窗框等哪一处观看；遮挡不妨碍关键信息 |
| 镜面或倒影 | 实体与反射的位置、观看对象；角色不因反射被计为新增角色 |

### 构图选择

- 对称居中：用于正面展示、仪式感或喜剧停顿，不固定排除居中构图。
- 引导线：说明桌沿、道路等如何指向主体或行动目标。
- 框中框：说明门窗等前景框的位置与主体所在区域。
- 留白：为视线或行动方向留空间，不固定留白比例。
- 倾斜构图：只有失衡表达确有需要时使用，保持方向连续，避免无意倾斜。

## 固定与运动：分别描述路径和速度

| 类型 | 摄影机实际变化 | 写清的内容 |
| --- | --- | --- |
| 固定 | 位置、朝向和焦段保持稳定 | 取景范围与主体入画/出画方向 |
| 推近 / 拉远 Dolly | 摄影机靠近 / 远离主体 | 起止取景、路径、幅度和速度 |
| 升降 Pedestal / Crane | 摄影机改变高度 | 起止高度、是否同时改变俯仰、揭示什么 |
| 横移 Truck | 摄影机向左 / 右平移 | 以画面或场景为参照的方向、起止位置 |
| 摇镜 Pan / Tilt | 机位不移动，水平 / 垂直转动朝向 | 起止观看对象、方向和速度 |
| 环绕 Orbit | 摄影机沿主体周围的弧线路径移动 | 以主体为中心的起止方位、绕行方向和距离 |
| 滚转 Roll | 摄影机绕镜头光轴旋转 | 倾斜方向、幅度及目的 |
| 变焦 Zoom | 机位不移动，焦段改变 | 起止取景与节奏；不冒充摄影机推近 |
| 跟拍 Tracking | 摄影机随主体移动 | 跟拍侧别、距离、速度关系和停止位置 |
| 拉焦 Rack Focus | 清晰焦平面改变 | 焦点从谁/什么转向谁/什么、触发节点 |

复合运镜只在观看目的需要时采用，先保证一条主运动清楚，再考虑第二条运动。三种以上同时变化时优先简化或分先后，不把“双轴上限”宣称为模型的硬限制。手持微震、镜头水珠、眩光等只在场景和风格需要时添加，不作为品质兜底词。

## 情绪与镜头选型参照

以下是候选，不是情绪到镜头的一对一公式；主体速度与摄影机速度独立决定。

| 观看目的 | 候选设计 | 检查重点 |
| --- | --- | --- |
| 看清反应 | Z3 近景 + Y4 平视 + X2 四分之三侧，固定 | 眼、耳、口鼻和小动作是否都可读 |
| 看清爪部操作 | Z2 局部或 Z5 中景 + 轻俯/顶视，固定 | 爪子、工具与操作结果能否同时看清 |
| 治愈日常 | Z5 中景 + 平视，固定或轻微移动 | 自然表演和柔光，不自动放慢动作 |
| 紧张揭示 | 起始遮挡构图或细节，再拉焦/切反应 | 新信息何时被看见，而非一律缓推 |
| 快速追逐 | 侧向全景，固定机位按路线切换 | 完整动作、方向和结果，保留主体速度 |
| 渺小或独处 | 远景 + 较高机位或背面构图 | 环境关系是否支持情绪，是否看得清主体 |
| 夸张出场 | 全景或四分之三身 + 低位仰拍 | 不因广角近距离意外改变角色脸型 |

多镜头可用“环境全景→操作细节→表情反应”递进信息，也可按剧情反向组织。固定镜头之间仍可快速切换；不把景别递进变成必需的铺垫。

## 审核表与最终正文

审核表中的摄影栏使用 `Z 景别 / Y 高度与俯仰 / X 方位 / F 必要属性 / 固定或运动`；写实际中文设计，编码可附加。光影色调和材质按 [aesthetic-constraints.md](aesthetic-constraints.md) 检查。

正文示例（已有“猫停止搅拌并看向锅中”情节时）：

> 台面左前方四分之三侧中景，摄影机略高于猫眼、轻微俯拍，固定机位；猫位于画面左侧，前爪、锅铲和右侧锅口均入画，猫脸与操作区同时清晰。猫前爪停住时，硬切到同侧锅口的俯拍特写，呈现锅内食物的状态。

示例只示范摄影表达，不替代实际剧情的表演和声音设计。素材继续按各自职责和对应镜头引用，不因采用编码而让所有参考图全程生效。

## 冲突检查

- 同镜是否既固定又平移/跟拍，或既推近又拉远而没有先后顺序；固定机位拉焦应另行说明。
- 是否混淆低机位与仰拍、侧面与横移、环绕与原地摇镜、推近与变焦。
- “缓慢”和“快速”是否修饰了同一对象同一阶段；主体快跑与固定机位、慢速移镜可以共存。
- 近景是否叠加不必要的大幅环绕，导致外形与空间难以稳定；能否减小幅度或换景别。
- 摄影方向、动作方向、参考视频运动方向是否一致，跨镜是否发生无意越轴或状态重置。
- 景深、取景范围和遮挡是否隐藏关键表演、爪部操作或动作结果。
- 连续性约束是否针对实际风险；不机械追加 4K/8K、无模糊、缓入缓出等通用词，不把运动模糊或合理虚焦一律排除。
