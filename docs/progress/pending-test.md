# 待测试

- 新增独立本地 `canvas-local-image-mcp`，Agent 可读取自身电脑上的 PNG、JPEG、WebP、GIF 或 AVIF 文件（最大 10 MB），经本机 Canvas Agent 服务导入画布并仅保存到浏览器本地，不上传云端。请验证配置并重启 MCP 后可导入图片、刷新画布后仍可读取，以及大于 10 MB 或不支持的文件会明确报错。
- 新建普通节点、连接节点、导入图片/音视频、粘贴文本及向画布发送视频后，视口会自动将新节点居中；Agent 按用户明确指令删除单个或多个节点时不再弹二次确认，并继续执行现有连线、任务和媒体清理。请验证新增节点聚焦及 Agent 删除行为。
- 从画布保存到“我的素材”的图片即使仅通过 `storageKey` 存储，拖入画布时也会先读取图片内容；素材缩略图不再触发浏览器原生图片拖拽打开新标签。请验证本地缓存和云端存储素材拖拽后都能正常显示。
- 本地 Go 后端默认端口已改为 `18080`，桌面一键启动脚本已同步设置后端端口和前端 API 代理；Docker 内部 API 仍使用 `8080`。请验证桌面脚本启动后 `http://localhost:3000/canvas` 可正常访问后端接口，同时现有占用主机 `8080` 的 Fusion 服务不受影响。
- 视频生成时，上游参考文本仅拼入实际生成请求，不再写入视频节点的提示词输入框；请验证生成成功、失败及重试后，输入框仍只显示原提示词，参考文本仍能参与生成。
- 画布 Agent 自动生成设置已拆分为图片、视频、音频独立开关；默认自动生成图片，视频和音频默认关闭。请验证开关分别保存到画布项目，并且启用/关闭某一媒体类型不会影响其他类型；关闭时只创建节点而不提交生成任务。
- Chengmeng `gpt-image-2-chengmeng` 画布图生图会将本地参考图先上传到已配置的又拍云，再以公网 HTTPS `image_url` 提交给 NewAPI；仅该模型使用此路径，成功、失败或创建异常后会清理临时对象。请验证已配置又拍云时图生图成功、未配置时提示明确、任务失败后不再残留又拍云对象，且其他图片模型仍按原请求方式工作。
- 画布配置中新增又拍云参考图上传；缺少公网 HTTPS 地址的视频参考图会在提交任务前经本机画布服务上传到又拍云，使用操作员和操作员密码的 REST API 鉴权。任务成功/失败结束或提交失败时会删除本次上传的临时副本；若清理失败，会在任务状态上保留对象 key 以便后续状态查询重试。配置保存在当前浏览器，请验证视频供应商能读取参考图、成功和失败任务都触发清理，以及未配置、鉴权失败、图片超过 50 MB 时的提示。
- NewAPI 视频任务完成后，优先上传/同步视频至配置的存储；若云端存储失败则回退到浏览器本地缓存。视频任务恢复轮询失败时，节点仍会自动重试，并在加载节点上显示具体错误，避免无提示地长期停留在 0%。请验证 NewAPI 视频成功回传、又拍云/服务端存储失败时仍可本地播放、页面刷新后任务恢复及错误提示。
- AICost/NewAPI 视频轮询兼容多层 `data.data` 响应，并将百分比进度（例如 `55%`）规范化为数值；请验证处理中响应继续轮询，只有明确失败状态才结束任务。
- 画布视频轮询遇到明确失败或请求异常时会切换为失败节点并显示错误信息；请验证 AICost 失败任务不再持续显示“正在创作”，且失败节点可以重试。
- 当上游网关返回 HTTP 200 但在错误消息中嵌入仍处于 `processing` 的 AICost 响应时，后端会继续轮询而不是提前结束任务；请验证该场景不会被标记为失败。
- AICost 返回 `content`/`content_url` 视频地址且内部状态为 `charged` 时，会按已完成任务处理；请验证画布能正常显示视频而不是进入失败状态。
- Hongcheng 视频轮询收到 HTTP 200 错误消息且其中嵌入任务结果时，会解析内层任务状态，识别 `succeeded` 并按完成处理；请验证该渠道成功任务不再显示 `Unknown Hongcheng video status`。
- 当 NewAPI 将 AICost 的 HTTP 200 响应截断后包装进 `body=` 错误文本时，后端会从残缺文本中恢复视频地址或处理中状态；请验证不会把有效响应误判为失败。
- 画布视频节点信息中新增请求日志，写入后端数据库并按登录用户和节点隔离，每节点最多保留最近 200 条；保存请求地址、模型、文本/字段请求体、响应或错误和耗时，不记录鉴权头，文件类表单只记录文件名、大小和类型。请验证超长提示词报错后可在节点“信息 > 请求日志”中查看并复制实际发送文本。
- 画布 Agent 新增批量删除节点工具；Agent 一次提交多个目标并由用户统一确认，确认后复用现有节点、连线和任务清理链路。请验证一次删除多个节点只弹一次确认，确认后全部删除，取消后全部保留，并验证单节点删除仍正常。
