# 默认按秒模式

仅在当前视频段使用默认模式时读取本文件。全部镜头遵循 [storyboard-rules.md](storyboard-rules.md)；用户明确要求固定30秒时，改读 `mode-fixed-30.md`。

## 分段与时长

- 每段按当前可自然完成的剧情设计，时长为5–30秒。按实际动作与必要反应定长度；不要求凑满30秒，不为满足时长拖长动作，也不添加空白停顿。
- 先按剧情节拍理解内容，再将完整视频时间线划分为连续、不重叠的秒数区间。时间段长短由内容决定，可为 `0–4s`、`4–9s` 等；不机械地每秒切一段，也不为均匀排版拆开动作。
- 一个时间段可包含一个或多个镜头；镜头切点根据叙事信息单独设计，不要求与时间段边界重合。
- 拆解表要写整段总时长和每个镜头的预计时长或时间范围，便于检查动作是否放得下。时长依实际动作估算，不统一乘比例、不额外加缓冲秒数。
- 角色动作余势或反应只有在剧情有表达作用时才占用时间，并写出具体可见内容。

## 提示词正文

按 Seedance 2.5 的提示词组织方式，在需要时采用“生成目标、参考素材职责、主体与场景、事件过程、视觉/镜头表达、声音、保持一致”等模块。分镜正文按连续秒数区间组织；每段交代发生的事件及可见结果，并在段内按观看信息安排具体镜头、表演、切点和声音。时长与画幅等生成参数由生成界面/接口设置，不需要在正文重复填写。

将已确认审核表中的 Z/Y/X/F 摄影设计转成自然语言；本段共用光影、配色和关键材质可并入主体与场景，必要时另列“视觉基准”。各时间区间只补本镜相关细节，按 [camera-codec.md](camera-codec.md) 与 [aesthetic-constraints.md](aesthetic-constraints.md) 检查，不强制写焦段数值或渲染器名称。

秒数区间用于分配事件节奏，不是精确剪辑点。区间连续、不重叠，覆盖本段内容。需要限定某个动作时长或延迟切镜时，可在对应区间内另写局部时长，例如“跪地保持3秒”“该动作开始2秒后切镜”；不得把每个时间段边界自动写成切镜点。

参考结构：

```text
【生成目标】
生成一段<视频类型>，核心主体是<主体>，主要事件是<本段故事概要>。

【参考素材职责】
@图片1用于<主体外貌/场景布局/道具结构>，仅在<对应时间段或镜头>采用<指定信息>。

【主体与场景】
<本段必要主体与空间关系；已确认视觉基准中的主光、总体色调及关键材质，可在此简述>。

【事件与镜头】
0–4s：<事件与结束状态>。<景别、机位高度与俯仰、相对主体方位、构图、必要景深/观看属性、固定或明确运动、动作表演、本镜光影材质差异和声音>。当<明确动作节点>时切到<切后景别、机位与新信息>。
4–9s：<下一段事件与结束状态>。<具体镜头、动作、反应及声音>。

【保持一致】
保持<角色身份、数量、位置、道具归属、空间方向和声音关系>稳定。
```

时间区间不是镜头编号，也不是阶段标题；同一段内可以按明确切点切换多个镜头。镜头参数要写实际摄影效果，不用“电影感”一词代替。
