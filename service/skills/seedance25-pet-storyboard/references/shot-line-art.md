# 镜头线稿审核总览

## 触发与用途

- 只有本单元所有镜头都已按逐镜设计流程完成并获用户确认后，才为该单元的全部镜头生成一张多宫格线稿总览；每个镜头各占一格，按镜头编号排列，不遗漏、不合并或增加镜头。使用一次画布图片生成调用完成整张总览，不逐镜生成后拼版。
- 总览用于用户检查机位、构图、角色站位及动作调度。它是独立审核图片节点，不是 Seedance 视频生成素材：不得放入视频提示词的参考素材清单，不得作为 `generate_video` 的 `sourceNodeIds`，也不得连到视频节点。
- 用户审核后等待其明确确认可以继续。若用户要求修改镜头，按其意见更新镜头设计；镜头审核表修改后不自动重生成线稿，只有用户明确要求生成或更新时才按最新镜头表重新生成整张总览。

线稿应让用户快速读懂每镜的关键构图、光线、空间关系、摄影机取景和动作路线，不画成追求完成度的插画，也不用细节纹理遮蔽调度信息。

## 生成与参考素材

- 只使用当前画布 Agent 实际提供的图片生成能力 `generate_image`。无角色参考时 `sourceNodeIds` 传空数组；使用已审核角色图片时只传真实相关的节点 ID。工具不可用时说明缺少的能力并等待可用入口，不自行改用 New API、本地生图 Skill 或其他 MCP，也不把结果下载到本机。
- 使用黑白铅笔分镜线稿，黑白灰画面配彩色标注。提示词中明确画格数量、镜头编号和阅读顺序；所有格子及图例须在一次调用中生成。
- 可使用已审核通过的角色图片节点来保持身份、脸型和毛色；只借用角色外观，不继承参考图姿势、背景、排版或光线。仅传真实且相关的图片节点 ID。没有已批准角色资产时按已确认的文字设定绘制。
- 每格中的实际姿态和动作都遵循项目适用的 `AGENTS.md` 及本 Skill 的角色姿态规则；持物或操作时明确以后肢支撑、以前爪执行，空手移动和休息时按情境采用合适姿态。

## 画面内容

- 每格呈现该镜头实际机位所见的一帧关键画面，并标清镜头编号；格子之间以清晰边界区分。整张总览共用一份颜色图例。
- 以黑白铅笔画呈现场景、角色、关键物品和明暗关系。画面本身保持黑白，彩色只用于下方规定的箭头与文字标注。
- 清楚表现主光源的位置、光线照射方向与角度、主要受光面和投影方向。必要时用光束箭头表示方向，并标出光源或角度说明。
- 清楚表现主要物品的位置与相互方位、角色站位、朝向及彼此关系。被标注对象应能与场景中的实际对象对应。
- 标明摄影机位置与朝向、视线范围，并注明景别；构图应体现该镜头实际能看到的范围，不凭空加入镜外信息。
- 用轨迹线表达该镜头中角色或物品运动，标明起点、方向、关键转折及必要的终点。若同一镜头有多条路线，应让每条路线及其所属主体容易区分。
- 只呈现理解该镜头调度所需的信息。剧本没有确定或该镜头无须表达的元素，不自行补成硬性设定。

## 标注颜色

每种信息类型使用固定颜色；箭头/线条与对应文字备注保持同色，并在图例中说明。黑白铅笔画不随标注类别染色。

| 类型 | 颜色 | 标注内容 |
| --- | --- | --- |
| 光照 | 橙色 `#D97706` | 光源、照射方向、角度、主要明暗或投影方向 |
| 摄影机与景别 | 青色 `#007C91` | 摄影机位置、朝向、取景范围、景别 |
| 角色站位 | 红色 `#C62828` | 角色位置、朝向、角色之间的空间关系 |
| 物品方位 | 蓝色 `#2457C5` | 关键物品的位置及彼此方位 |
| 运动轨迹 | 紫色 `#7B2CBF` | 角色或物品的移动路径、方向和关键节点 |

运动轨迹用带箭头的虚线，与表示静态位置的标记区分。箭头尖端表示运动方向；若运动需要先后次序，使用数字标注节点，并在同色文字中简短说明。其他箭头避免交叉遮挡主体或关键动作。文字应简短、可读、贴近所说明的箭头或对象；颜色不易辨认时，使用白底小标签辅助对比，但保持线稿主体为黑白。

## 交付检查

- 每个已确认镜头恰有一个对应格子，编号和阅读顺序清楚；没有遗漏、合并或擅自增加镜头。
- 光照、机位/景别、角色站位、物品方位和运动轨迹等信息按需要表达，彼此不会混淆。
- 角色姿态符合已确认的场景、动作和项目规则；线稿没有改变镜头设计或添加未经确认的事件。
- 箭头方向明确，颜色与图例及备注一致，文字不遮挡关键画面。
- 总览作为独立图片节点交用户审核；不将其当作视频生成参考，不上传或关联到视频节点。它不取代提示词中的时长、动作过程、连续性和声音要求。
