# 镜头 / 动作拆解审核表

本表按镜头逐步累积。必须遵循 [shot-by-shot-design.md](shot-by-shot-design.md)：每轮只设计并审核当前镜头，逐项澄清后填写该镜头完整的一行；用户确认当前镜头无问题后才处理下一镜。用户修改时先更新当前镜头并复核。单元所有镜头确认、线稿总览审核通过前，不附可提交的完整视频提示词。

本表作为当前视频单元唯一的画布文本节点维护：创建后持续更新，不为同一审核表重复创建节点。只把用户已确认的镜头写入累计表；当前待审镜头先在 Agent 会话中完整呈现。

- 事件区间连续、不重叠并覆盖本段。多个镜头属于同一事件时可填写同一事件区间；同一镜头跨事件区间时列明其覆盖区间，不为排表人为切镜。
- 本镜预计时间范围用于核查动作容量；切镜由动作触发节点独立说明，不把事件区间边界自动视为切镜点。最后一镜注明本单元结束状态。
- 摄影栏写中文实际效果，Z/Y/X/F 编码可辅助标注；不要求填满 F 属性或写固定焦段。具体参照 [camera-codec.md](camera-codec.md)。
- 光影栏按 [aesthetic-constraints.md](aesthetic-constraints.md) 写与本镜有关的细节，不为填表新增道具、特效或风格。
- 角色表演、声音和切点遵循 [storyboard-rules.md](storyboard-rules.md)。只有本单元所有镜头逐一确认且线稿总览审核通过后，才将完整设计转为对应时间段的自然语言提示词；不能只留在表里，也不能在单镜确认后提前撰写整段提示词。
