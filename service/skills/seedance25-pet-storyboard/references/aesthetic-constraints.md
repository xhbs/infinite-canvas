# 深度美学约束：光影、材质、色调与构图

改编自 [seedance2.5-prompt-skill / aesthetic-constraints.md](https://github.com/ye4wzp/seedance2.5-prompt-skill/blob/b093438a133ebc3fe81cd1be214271a222516919/references/aesthetic-constraints.md)。原作版权与 MIT 许可见 [许可文件](../licenses/seedance2.5-prompt-skill-MIT.txt)。保留光照、材质、配色和构图方法；渲染器品质词与强风格配置按项目选用。

## 选用原则

先检查剧本、已确认风格和参考素材职责，写出当前镜头真正看得见的美术信息。未限定的普通细节留给模型补足；不为使用本模块新增剧情道具、雾气、灯光装置或审核环节。重要风格选择影响既有设定时，在本段审核表中说明后随表审核。

- 全局确定主光逻辑、总体色调和关键材质；每镜只补变化或决定观看效果的细节，避免重复堆词。
- 日常萌宠镜头优先保持角色毛色、食物颜色和生活空间可信。日常、写实、卡通或 3D 风格由已确认设定决定，不统一改成 Octane、赛博或广告风。
- 光学与取景见 [camera-codec.md](camera-codec.md)；美术要求不能使关键动作不可见，或与景深、摄影机方向相冲突。

## 光影：光源 → 光行为 → 可见结果

有助于画面时说明光源类型与方向、光线软硬及明暗关系，再描述光如何落在主体、物件和空间上。只写“柔美”“高级”“电影级”不足以交代效果。

| 维度 | 可用描述 | 使用条件与限制 |
| --- | --- | --- |
| 主光与补光 | 左侧窗外柔光、暖色灶灯、较暗的背光侧 | 方向以场景为参照，摄影机换位后光源仍在原处 |
| 阴影与接触 | 爪子压住台面处有接触阴影，投影方向与主光一致 | 不用无阴影的均匀亮度替代物体接触关系 |
| 间接光 / GI | 墙面与台面的柔和反射照亮暗侧，暗部保留层次 | 需要这种反弹光效果时描述，不必每镜加 GI 术语 |
| 次表面散射 / SSS | 薄耳缘被逆光照得轻微透亮 | 只用于相关薄皮肤或半透明材质，避免整只猫变蜡质 |
| 体积光 | 窗边已有薄雾中可见柔和光束 | 场景有雾、尘或蒸汽且确有需要时用，不额外造烟 |
| 焦散 | 玻璃或水面折射在邻近表面形成光纹 | 需要相应物体与光路，普通镜头不自动添加 |
| 环境映射 / HDRI 观感 | 金属表面反射实际窗户与室内环境 | 描述反射内容和强弱，不当作接口设置 |
| 光线衰减 | 靠近灯处较亮、远处自然变暗 | 不机械填写数值；暗处仍需看得清剧情信息 |

“暖”“冷”优先描述画面观感或光源性质；除非任务需要精确灯光设计，不堆色温数值、光比或色彩空间名称。亮部保留毛发和食物细节，暗部保留动作轮廓。

## 材质：挑本镜头可辨认的特征

| 材质 | 具体可见的表达 | 避免 |
| --- | --- | --- |
| 毛发 | 毛流随身体结构分布，轮廓细毛被侧光勾亮，毛色分区稳定 | 塑料壳般统一高光、额外增毛、每根毛都过锐 |
| 鼻尖与肉垫 | 鼻尖微湿且高光克制，肉垫有柔软接触感 | 把整张脸涂成湿亮塑料 |
| 金属锅具 | 曲面高光随形体连续变化，反射对应厨房环境；近景可见细微使用划痕 | 无来源反射、液态变形、远景强塞微划痕 |
| 玻璃 | 透明度、边缘反射与背景折射关系清楚 | 把普通透明杯写成强烈彩虹棱镜 |
| 陶瓷 | 釉面柔和高光，器口和底部体积清楚 | 与金属共用同一反射外观 |
| 织物 | 围裙或桌布有织纹、折痕和顺重力下垂 | 所有织物都成清漆表面 |
| 食物 | 依据实际状态选酥脆纹理、湿润切面、薄亮酱汁等可见特征 | 未有剧情依据就增加热气、冒泡、油滴或流动 |
| 液体 | 液面、黏度、附着与流动跟随实际动作，必要时见弯月面 | 将静止液体强制写成飞溅特效 |
| 木材 / 塑料 | 木纹方向、哑光粗糙度或局部清漆光泽 | 材质混淆、无意义微观噪点 |

只约束关键材质，不列场景里所有物体。材质细节应随景别可见，不让纹理描述淹没动作、表情和声音。

## 色调：全片基准与局部差异

交代主色、辅助色、明暗区及主体与背景的分离方式。保留角色识别色和道具本色，避免逐镜换滤镜。冷暖对比可来自窗光与室内光、主体与背景，不要求每幅画都强烈分成冷暖两半。

| 可选配置 | 颜色关系 | 适合与限制 |
| --- | --- | --- |
| 自然日常 | 中性或轻暖环境，食物和毛色自然 | 日常萌宠与厨房生活；明暗温和但保留体积 |
| 暮光渐变 | 暮紫 / 深青暗部，落霞粉 / 暮金亮部 | 黄昏或温柔叙事；不覆盖角色本色 |
| 极简白金 | 米白 / 浅灰背景，少量金色与深色锚点 | 干净产品或食物展示；白毛和白盘仍有层次 |
| 冰火对冲 | 深蓝暗部与红橙亮部形成对比 | 用户要求的冲突或强风格段落，不默认用于厨房 |
| 赛博霓虹 | 深蓝 / 电紫背景，霓虹红 / 橙高光 | 明确的夜间或赛博设定，不凭空加入霓虹灯 |
| 赛博冷调 | 炭灰背景，冰蓝与少量绿色点缀 | 明确的科技场景，不自动映射为角色毛色 |
| 极简黑白 | 黑白明度结构加单一点缀色 | 明确的时尚或实验风格，需与角色识别要求相容 |

需要固定配色时，可参考原作色板：暮紫 `#2D1B69` / 暮金 `#FFC371`，米白 `#F5F5F7` / 金 `#FFD700`，深蓝 `#001F3F` / 橙红 `#FF4136`，深空蓝 `#0A0E27` / 电紫 `#6C3EFF` / 霓虹红 `#FF2D55`。HEX 是选色参照，不能保证生成视频逐像素复现；通常写可见颜色关系即可。

## 构图：突出信息而不固定比例

- **减法**：清理与本镜表达无关的显眼干扰物，保留剧情、空间辨识和生活真实感需要的元素；不限制画面只能有三个物件。
- **留白**：为角色视线、运动路线和操作空间留余地；不设固定 30% 留白，不以留白挤掉关键爪部动作。
- **视觉锚点**：按表达选择居中、对称、三分、对角线或引导线；镜头中的第一注意点应是本拍关键角色或物件。
- **层次**：用前中后景、遮挡、明度或色温建立纵深；不要求三层全部存在，不把前景/背景虚化当成唯一办法。
- **连续性**：背景的空间布局、关键道具、主光方向和基础配色跨镜保持一致；光影变化须有场景或事件依据。

## 渲染品质词：可选的风格锚定

用户要求 3D 或商业渲染风格时，可用 Octane / V-Ray / Arnold 作为观感参照，随后写具体光影和材质效果。这些词不能保证模型实际使用该渲染器，也不改变输出分辨率、帧率或色彩空间。

日常镜头可以直接写：

> 窗侧柔光照亮猫脸和操作台，暗侧由室内反射光轻微提亮；毛流清楚、轮廓柔和，金属锅沿反射窗户亮面，食物颜色自然，画面注意点落在前爪与锅口。

明确选择 3D 渲染风格时可以写：

> 延续已确认的 3D 萌宠造型，以 Octane 渲染观感为参照；柔和间接光保留暗侧体积，毛发为细软纤维质感，陶瓷和金属呈现不同高光，保持角色原有毛色与脸型。

不自动追加全套 GI、SSS、焦散、体积光、耀斑、8K 等词。不把所有镜头都推成高饱和、大光比、强锐化或浅景深。

## 如何写入审核表与提示词

本段审核表前可用一句话写“视觉基准”：主光逻辑、总体配色、关键材质与构图倾向。已有明确基准时引用并仅写差异；该说明属于审核表的设计信息，不是可提交的完整视频提示词。

每镜“光影/色调/材质”栏写本镜能看到且有表达作用的细节；可写“沿用本段基准”，有特殊反光、逆光或材质细节时再补充。确认后的提示词在“主体与场景”或可选“视觉基准”中写共用设定，在相应秒数区间写本镜差异。

## 提交前检查

- 主光有明确来源和方向，投影、反射及跨镜照明是否合理一致。
- 主体表情、操作和结果在光比、景深、遮挡中是否仍可读。
- 材质细节是否适用于实际物体与当前景别，是否引入了剧本没有的状态或特效。
- 色调是否延续已确认风格，是否保留角色毛色、食物本色及关键道具识别。
- 构图是否服务观看信息，是否机械套用了元素数量、留白比例或冷暖对半分割。
- 是否以可见效果支撑品质要求，避免只剩渲染器名称和通用形容词。
