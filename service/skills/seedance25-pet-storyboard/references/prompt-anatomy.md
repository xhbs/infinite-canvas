# Seedance 2.5 提示词模板与镜头示例

本文件把官方指南中的提示词组织方法用于萌宠剧情视频。保留本 skill 已确认的镜头、表演、声音和素材规则；事件正文按秒数区间组织。用户已有提示词开头或结尾声明时，保留其原有职责和措辞。

## 组织原则

Seedance 2.5 官方指南的基础组织公式为：

`主体 + 动作/事件 + 场景与环境 + 视觉风格 + 运镜/切镜 + 声音`

长内容还要说明生成目标、参考素材职责，以及重要状态的一致性。根据本段需要组织这些模块，不要求每个提示词都填满全部标题。生成时长、画幅等由生成界面/接口设置；正文中的秒数区间用于描述事件节奏，不是生成参数，也不是精确剪辑点。

镜头具体写法由 [camera-codec.md](camera-codec.md) 的 Z/Y/X/F 检查支撑，光影、色调、材质与构图由 [aesthetic-constraints.md](aesthetic-constraints.md) 支撑。先以 [shot-review-template.md](shot-review-template.md) 提交具体设计，确认后再转为本文件的完整提示词。最终正文使用中文实际摄影描述，不强制显示编码或光学数值。

## 通用模板

```text
【生成目标】
生成一段<视频类型>。核心主体是<主体>，主要事件是<本段故事概要>。

【参考素材职责】
@图片1用于<主体外貌、服装、结构或材质>，只采用<指定信息>，不采用<容易误带的内容>。
@图片2用于<场景布局、道具形制或光线>，只在<时间区间/镜头>调用<指定信息>。（如适用）
@视频1用于<动作、运镜或节奏>，不采用<无需继承的信息>。（如适用）
@音频1用于<指定角色或声音类型的音色/台词/环境声>。（如适用）

【主体与场景】
<主体身份、数量、外观、初始位置及关键道具归属>。
<地点、空间关系、时间/天气或必要的画面风格>。

【视觉基准】（需要单列时使用，也可并入主体与场景）
<已确认画面风格；必要的主光来源与方向、明暗/色彩关系、关键材质和视觉重心>。

【事件时间线】
0–4s：<事件及可见结果>。<Z 景别、Y 高度与俯仰、X 方位、构图与主体位置、F 必要光学/观看属性，均写实际含义>；<固定或明确运动路径与节奏、动作/表演、本镜光影材质差异、切点和对应声音>。
4–9s：<下一事件及可见结果>。<按观看信息安排具体镜头、动作/表演、切点和对应声音>。

【保持一致】
保持<角色身份与数量、服装/外观、道具归属、方位、状态及其他关键连续性>一致。

【声音】
<全片声音限制；各段声音仍要对应到具体角色、动作或环境。>
```

不适用的素材类别可省略。素材映射和事件顺序必须明确；角色表演、镜头切点及声音不能只放在全局设定或结尾总结里，应写入对应时间段和镜头。

视觉基准只写本段共用、确有作用的信息。每镜沿用共用光影与材质时无需重复整段；有新的观看信息或局部差异时再补充。不为了填模板加入新道具、渲染特效或强烈配色，不将浅景深、50mm、缓慢运动设为默认。原有开头/结尾声明无需为了容纳这些设计而改写。

## 时间区间与镜头

- 时间区间按事件节奏分配，可长可短，例如 `0–3s`、`3–8s`、`8–14s`；不强制等分，也不机械逐秒切片。所有区间连续、不重叠，并覆盖本段事件。
- 一个区间可以包含多个镜头，同一镜头也可跨越区间边界。区间边界不自动切镜；需要剪切时，另写触发动作、切后景别/机位/构图和新信息。
- 每个镜头按需要写明确的景别、机位方向与高度、角度、构图/主体位置、固定或具体运镜，以及观看目的。焦距等参数仅在确有帮助时写。实际摄影结果比堆砌术语更重要。
- 镜头高度以当前主体眼睛、台面或地面为参照；多主体镜头明确方位参照。景深写清谁/什么清晰、谁/什么虚化，不能隐藏关键操作。场景光源不随摄影机换位而自动转向。
- 时间范围代表事件的节奏预算，不是精准剪辑点。只有固定动作时长或延迟切镜时，才在对应区间里另标局部时长。
- 单次短促动作默认在一个镜头内完成必要过程和直接结果。若某个较长动作确实设计为跨镜，切点须落在清晰的进行节点，下一镜从同一动作接续，不重置、不等待。

## 示例：逗草尖，猫扑空后追逐

以下示例使用秒数区间；每个区间内部独立安排具体镜头。动作速度与摄影机运动分开设计，成组表演在同一情绪拍内协同呈现。

```text
【生成目标】
生成一段轻松俏皮的萌宠短片：小狗用狗尾巴草逗猫，猫扑空后立刻追逐小狗。

【参考素材职责】
@图片1只定义猫的毛色、脸型和体型；@图片2只定义小狗的外形。两张角色图不提供场景和构图。

【主体与场景】
猫在草地左侧，小狗在右侧，狗尾巴草由小狗前爪夹持。晴天草地，篱笆缺口在画面左后方。

【视觉基准】
延续参考图的角色造型。日光由篱笆一侧斜照草地，两只动物毛发受光柔和、毛色自然，爪子与草地接触处有轻微阴影；草地和篱笆配色克制，角色与草尖是视觉重心。

【事件时间线】
0–4s：小狗快速把狗尾巴草左右扫过猫鼻尖前。摄影机位于两只动物的侧前方，略低于猫眼、镜头水平，采用固定全景，两只动物全身同框，猫在左、狗在右，右侧保留扑击与落地空间；两只动物及草尖均清晰。猫盯着草尖，耳朵逐渐压低，肩背收紧、后腿蹬住地面、尾巴绷直；同时瞳孔紧跟草尖急转，鼻翼轻颤、口鼻收紧，整组表演呈现被挑逗后的恼火和蓄势。猫突然爆发式向右扑出，前爪伸向草尖并落地扑空；这个短促扑击及落地结果完整留在同一镜头，摄影机不跟拍。声音：<草穗快速划过空气的唰声><猫爪蹬地和落地的沙响>。
4–7s：猫扑空落地后，硬切到小狗正侧面中景，摄影机与狗眼等高、水平固定；狗面向画面左侧的猫，头部和前爪入画，右侧留出后撤空间。小狗向后跃开并落稳，肩背一缩、前爪收近身体，耳朵一下竖起，眼睛转向猫、嘴微张；狗尾巴草仍由其前爪夹持并在画面下缘晃动。用这个新构图呈现小狗的躲闪反应；狗脸、前爪与草穗保持可辨，不用过浅景深隐藏互动。声音：<狗爪急刹蹭草声>，随后保留轻微草地环境声。
7–12s：小狗后爪蹬地、朝缺口转头时，硬切到路线外侧的侧向大全景，摄影机位于站立成人腰部高度、轻微俯拍，固定机位；篱笆缺口位于画面左侧。小狗带着草穗由右向左爆发加速，猫立即追上，耳朵后贴、目光锁定狗，肩背前压、尾巴绷直，连续急促地冲出画面，动作是短促快跑。猫刚冲出画面时硬切到缺口另一侧、行动轴线同侧的广角全景，摄影机与奔跑动物眼睛近乎等高，水平固定；两只动物全身按同一画面方向先后入画并穿过缺口，背景篱笆仍可辨，摄影机留在原地。声音：<连续急促的爪子踩草声><草穗拍打叶片的刷刷声>，声音随两只动物远去而减弱。

【保持一致】
猫和小狗身份、体型、毛色、运动方向稳定；狗尾巴草始终由小狗持有；篱笆缺口的位置固定。

【声音】
不使用背景音乐、旋律或节拍，不显示字幕或画面文字；各镜头只保留已标明的动作声与轻微环境声。
```

## 检查重点

- 事件区间是否按秒数连续、不重叠；每段是否安排真实事件，而非无意义填时。
- 每镜是否写出可执行的摄影设计，且切点独立于区间边界。
- 是否以 Z/Y/X/F 检查景别、高度与俯仰、方位、必要光学/构图；摄影和运动描述是否互相兼容。
- 视觉基准是否具体且符合已确认风格；光影材质是否跨镜一致、随景别可读，并服务关键表演和操作。
- 短促动作是否在一个镜头内呈现过程与直接结果；只有确需贯穿多镜的动作才跨镜连续。
- 剧情角色是否有一组相互配合的身体小动作和一组可读表情线索；声音是否落实到具体镜头。
- 参考素材是否按职责调用，角色、道具、方位和状态是否连续。
